# Redaktionsstöd.se MVP

Professionell MVP-hemsida för en svensk konsulttjänst inom GDPR- och dokumentgranskning med AI-stöd för offentlig sektor.

## Innehåll

- Startsida
- Tjänster
- Så fungerar det
- Säkerhet & sekretess
- Exempelgranskning
- Priser/offert
- Kontakt

## Viktiga avgränsningar

Webbplatsen beskriver tjänsten som beslutsstöd, granskningsstöd och kvalitetssäkring. AI:n fattar inte beslut och tjänsten ersätter inte ansvarig organisations egen sekretessprövning eller juridiska bedömning.

## Utveckling

```bash
npm install
npm run dev
npm run build
npm run lint
```
